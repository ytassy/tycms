# SEC-004 — Autorités URL malformées dans Symfony HtmlSanitizer

État : vérifiée localement — version affectée remplacée ; production non vérifiée.
Lots : 02, 09. Révision initiale : `df84bd5a9bf9e56766bb380471d7a101a69907d0`.
Classement projet : renforcement ; contournement applicatif non démontré.
Confiance : forte sur la version ; preuve applicative limitée à l'URL et au
profil sondés, pas à toutes les variantes de liens/médias.

## Comportement, preuve et protections

Avis [CVE-2026-118517](https://symfony.com/cve-2026-118517),
`PKSA-n87g-t5cn-m1yq`. L'audit conservé n'indique pas d'identifiant GHSA pour
cet avis ; ne pas en déduire un à partir de l'identifiant PKSA.
HtmlSanitizer 8.1.8 peut contourner `allowLinkHosts`/`allowMediaHosts` avec des
URL sans autorité bien formée. L'exploitation nécessite un contenu non fiable
et un profil qui se repose sur ces listes pour interdire une destination.

Le WYSIWYG ajoute `WysiwygMediaSourceAttributeSanitizer` : refus des `src`
d'image commençant par `//` ou par un schéma, normalisation vidéo dédiée et
préfixe `/medias/` pour les vidéos (`:23–35`, sous
`src/releases/vdev/framework/Lib/HtmlSanitizer`). La sonde d'image
`///refuse.example/a.png` est refusée avant/après correction. Le profil e-mail
lu n'établit pas de liste d'hôtes ; les autres URL et profils restent au lot 09.

Preuves : [audit initial](../../Evidence/LOT-02/composer-audit.json),
[sondes avant](../../Evidence/LOT-02/applicability.json) et
[après](../../Evidence/LOT-02/applicability-after.json).

## Décision, correction et vérification

Yann a autorisé la mise à jour compatible **HtmlSanitizer 8.1.11**, plutôt
qu'une exception d'audit fondée sur le seul filtre média actuel.
L'avis disparaît de l'audit Composer et la sonde de refus reste vraie ; les
tests HTML/e-mail ciblés réussissent.
[Résultats et limites](../../Reports/LOT-02.md#vérifications-et-traçabilité).

Pas de changement d'autorisation des médias ni de migration. Réouvrir pour
un autre profil vulnérable, un nouvel avis ou la réintroduction d'une version
affectée ; aucune conclusion globale sur toutes les URL n'est acquise.
