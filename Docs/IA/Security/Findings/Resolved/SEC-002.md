# SEC-002 — Contrôle des URL srcset dans Symfony HtmlSanitizer

État : vérifiée localement — version affectée remplacée ; production non vérifiée.
Lots : 02, 09. Révision initiale : `df84bd5a9bf9e56766bb380471d7a101a69907d0`.
Classement projet : renforcement ; contournement applicatif non démontré.
Confiance : forte sur la version et le refus des sondes ; pas d'audit exhaustif
de tous les profils HTML ni de validation navigateur.

## Comportement, preuve et protections

Avis [GHSA-q8jq-xrf4-v5j8](https://github.com/symfony/symfony/security/advisories/GHSA-q8jq-xrf4-v5j8),
`CVE-2026-121949`, `PKSA-wwnc-rwy3-v11m`. HtmlSanitizer 8.1.8, verrouillé en
production, ne contrôle pas suffisamment les URL de `srcset`/`imagesrcset`.
Un auteur HTML non fiable pourrait contourner une restriction de schéma/hôte
si un profil autorisait ces attributs en leur faisant confiance.

Les profils lus ne les autorisent pas :
`framework/Lib/HtmlSanitizer/HtmlSanitizer.php:57–86` et
`Core/Helper/Mail/EmailTemplateContent.php:153–168`, sous `src/releases/vdev`.
Les sondes WYSIWYG et e-mail retirent `srcset` avant **et** après correction ;
`imagesrcset` est couvert par la lecture de la liste d'attributs, pas par une
sonde distincte. Aucune XSS ni requête navigateur interdite n'a été reproduite.

Preuves : [audit initial](../../Evidence/LOT-02/composer-audit.json),
[sondes avant](../../Evidence/LOT-02/applicability.json) et
[après](../../Evidence/LOT-02/applicability-after.json).

## Décision, correction et vérification

Yann a retenu la mise à jour compatible de **HtmlSanitizer vers 8.1.11**, plutôt
que dépendre seulement du refus actuel des attributs. Aucun élargissement de
profil HTML ni migration des contenus enregistrés n'a été réalisé.

Audit Composer après correction sans cet avis, sondes de refus réussies et
tests HTML/e-mail ciblés réussis ; voir les
[résultats communs](../../Evidence/LOT-02/verification.json).
Les parcours HTML complets restent au lot 09. Réouvrir si un nouveau profil
autorise ces attributs, si l'avis évolue ou si une version affectée est réintroduite.
