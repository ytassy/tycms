# SEC-005 — Vue SSR présent dans le verrou du build LMS

État : vérifiée localement — version affectée remplacée ; production non vérifiée.
Lots : 02, 09, 14. Révision initiale : `df84bd5a9bf9e56766bb380471d7a101a69907d0`.
Classement projet : renforcement ; parcours SSR exploitable non identifié.
Confiance : forte sur le verrou et le build client ; aucune preuve navigateur
ou serveur d'une exploitation SSR dans TyFramework.

## Comportement, preuve et protections

Avis [GHSA-g2v6-rqmx-r4w6](https://github.com/advisories/GHSA-g2v6-rqmx-r4w6),
CWE-79/CWE-116, gravité **élevée amont**. L'avis signale une liste d'exclusion
incomplète des noms d'attributs dans `@vue/server-renderer` avant 3.5.42.
Un scénario XSS suppose un rendu SSR traitant les noms concernés comme une
entrée non fiable ; la présence du paquet seule ne prouve pas cette chaîne.

Le verrou `src/extensions/plugins/Lms/frontend/package-lock.json` contient
3.5.38 initialement. Le manifeste le déclare dans les dépendances de build ;
`frontend/vite.config.mjs:5–8` utilise `src/tools/extension-vite.mjs:34–46`
pour produire une bibliothèque ESM cliente avec runtime commun partagé.
Aucun parcours SSR n'a été identifié dans le périmètre LMS examiné.

Preuves : [audit LMS initial](../../Evidence/LOT-02/lms-audit.json),
[audit final](../../Evidence/LOT-02/lms-audit-after.json) et
[empreintes finales](../../Evidence/LOT-02/sources-after.json).

## Décision, correction et vérification

Yann a retenu l'alignement compatible sur **Vue 3.5.43** et sa famille `@vue/*`,
plutôt qu'une simple exclusion de l'avis au motif de l'absence de SSR.
`csstype` passe de 3.2.3 à 3.2.4 transitivement, sans ajout/suppression de paquet.

Installation sans scripts et build LMS Vite 7.3.7 réussis dans une copie isolée,
sans asset du dépôt régénéré. L'avis Vue disparaît de l'audit LMS ; picomatch
reste ouvert dans [SEC-006](../UnderReview/SEC-006.md).
[Résultats communs](../../Evidence/LOT-02/verification.json).
Réouvrir si du SSR est ajouté, si le verrou régresse ou si l'avis est élargi.
